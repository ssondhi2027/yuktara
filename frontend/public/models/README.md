# Anatomy 3D models

The adapted 3D meshes used by the iOS app *Anatomy 3D: Bones & Muscles*: every bone, skeletal muscle and
ligament as glTF 2.0 (meshopt + quantized), one node per structure named `ta2-<Terminologia Anatomica 2 id>.<side>`.

| File | Content |
|---|---|
| `bones.glb` | bones and teeth |
| `muscles.glb` | skeletal muscles |
| `ligaments.glb` | ligaments, capsules, discs |
| `index.json` | node index: bounds, tissue layer, landmarks |
| `credits.json` | per-node source, licence and modification note |
